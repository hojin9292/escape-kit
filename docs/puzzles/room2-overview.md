# 「먹고 마시는 방」(먹고 마시기) — 방 설계서

> `docs/puzzles/room1-overview.md`(1번 방)의 절 구성을 따른다.

방 = `food-room` — 급식실/부엌 한쪽의 식사 공간. 배경 아트는 아직 없다(뼈대 단계,
1번 방과 동일한 사정 — 이미지 생성 도구가 이 세션에 없음). 크기는 임시 14×14.
6방 계획의 **2번 방**. 「딱! 이만큼」 앱의 food 카테고리(FO-001~020) 20문항 중
4문항을 퍼즐로 사용하고, 마지막에는 그 네 활동을 복습 보드에서 다시 확인한다.

**방 방향**: 1번 방과 같은 접근성 원칙(이산 탭만, 반응속도·소근육 정밀도가 판단을
가리지 않게). 이 방에서는 **표면을 직접 문질러 바르기**와
**주문표를 보고 세 그릇 비교하기**를 사용한다.

## 방 구조

```
입장 (spawn) ─ P1 물 따르기 / P2 얼음 넣기 / P3 잼 바르기 / P4 요거트 토핑
              (네 곳 모두 봉인 밖 — 순서 자유)
식탁 정리대 코너 [sealed shelf-corner, opensWhen: 4개 code:*-solved 전부]
  ─ 최종 콘솔 pour-shelf-order(복습 보드, gate 없음) → door:food-open → 출구
```

1번 방과 같은 뼈대(4개 자유 순서 퍼즐 + 봉인된 코너 + 복습 보드)를 그대로 쓴다 —
방마다 새 구조를 발명하지 않는 것이 학생에게도, 유지보수에도 유리하다.

## 정보 배정표 (코드 조각 대신 — 각 퍼즐이 공개하는 정보)

| 퍼즐 | 근거 문항 | 조작 | 판정 핵심 | 보상(이벤트) |
|---|---|---|---|---|
| P1 water-pour | FO-001 | **탭으로 따르기**(누를 때마다 물 높이 증가, "그만 따르기" 확정) | 컵에 표시된 안전선 | `code:water-solved` |
| P2 ice-drop | FO-008 | **탭으로 넣기 횟수 세기**(되돌리기 없음) | 주문표의 2~3개 | `code:ice-solved` |
| P3 jam-spread | FO-005 | **빵 위를 직접 문질러 바르기** | 넓이와 고른 분포 | `code:jam-solved` |
| P4 yogurt-topping | FO-017 | **세 그릇 비교 선택** | 주문표의 한 숟가락 | `code:topping-solved` |
| 최종 pour-shelf-order | FO-001·008·005·017 | **활동 카드 확인**(순서 없음) | 네 장 모두 확인 | `door:food-open` |

조작 4종 중복 없음: 채우기(누적 후 확정, 1번 방 toothpaste와 같은 계열이지만 이 방
안에서는 유일) / 횟수 세기(1탭=1개, 되돌리기 없음) / **문질러 펴 바르기** /
**주문표와 완성 그릇 비교하기**로 구성한다.

## P1 `water-pour` — 물 따르기 (FO-001) · 하

- 컵 그림. [따르기] 버튼을 탭할 때마다 물 높이가 한 단계씩 오른다(이산 스텝).
  [그만 따르기]로 확정, [덜어내기]로 확정 전 한 단계 되돌리기 가능.
- 정답 구간: 컵 그림에 표시된 안전선(내부 판정값 55~78).
- 보상: `code:water-solved`.

## P2 `ice-drop` — 얼음 넣기 (FO-008) · 하

- 컵에 얼음을 하나씩 넣는 그림. [넣기] 탭마다 얼음이 1개씩 쌓인다. 되돌리기 없음
  (한 번 넣은 얼음은 꺼내지 않는다는 자연스러운 제약 — hand-sanitizer-pump와 같은
  설계). 오답(too high) 확정 시 컵을 비우고 재도전.
- 정답: 이번 주문표의 2~3개.
- 보상: `code:ice-solved`.

## P3 `jam-spread` — 잼 바르기 (FO-005) · 중

- 식빵 위를 손가락이나 마우스로 문지르면 숟가락이 따라 움직이고 잼 자국이 이어진다.
- 내부 판정은 6×4의 보이지 않는 거친 셀을 사용해 45~72% 면적과 3개 이상 행·5개 이상
  열의 분포를 함께 확인한다. 한쪽에 몰리면 빈 쪽으로 펴 바르도록 안내한다.
- 보상: `code:jam-solved`.

## P4 `yogurt-topping` — 요거트 토핑 (FO-017) · 중

- 토핑 없음·한 숟가락·가득 덮기 세 그릇을 비교한다.
- 주문표의 ‘토핑 한 숟가락’과 같은 그릇을 고른다. 자동 진행과 반응속도 요소는 없다.
- 보상: `code:topping-solved`.

## 최종 `pour-shelf-order` — 식탁 정리대 복습 보드 · 하

- 4개 퍼즐을 모두 풀면 정리대 봉인이 걷히고 이 장치가 열린다.
- 물 따르기·얼음 넣기·잼 바르기·요거트 토핑 카드가 2×2로 표시된다.
- 어떤 순서로든 네 장을 누르면 도장이 0/4에서 4/4로 쌓인다. 오답과 초기화는 없다.
- 네 장을 모두 확인하면 `door:food-open`을 발화한다.
