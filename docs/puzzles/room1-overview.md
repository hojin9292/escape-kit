# 「깨끗한 방」(몸과 주변을 깨끗이 하기) — 방 설계서

> `docs/puzzles/room3-overview.md`(예제)의 절 구성을 따른다.

방 = `hygiene-room` — 교실 한쪽의 청소 공간. 배경 아트는 아직 없다(뼈대 단계).
크기는 임시 14×14 — 배경을 나중에 얹으면 캘리브레이션에 맞춰 조정한다.
6방 계획의 **1번 방**. 「딱! 이만큼」 앱의 hygiene 카테고리(HY-001~020) 20문항 중
4문항을 퍼즐로, 4문항(별도)을 최종 서열 퍼즐로 재사용한다.

**방 방향**: 특수교육 대상 학생(지적장애·자폐성장애·발달장애). 반응속도·소근육
정밀도가 판단을 가리면 안 된다 — **모든 조작은 이산적인 탭**(드래그·슬라이더·타이밍
압박 금지). 정답은 항상 "판단 결과 즉시 반응"으로 보이게 하고(무오류 학습), 확인
전 되돌리기를 허용한다.

## 방 구조

```
입장 (spawn) ─ P1 치약 짜기 / P2 손 소독제 펌프 / P3 양치 시간 / P4 화장실 휴지
              (네 곳 모두 봉인 밖 — 순서 자유)
정리대 코너 [sealed shelf-corner, opensWhen: 4개 code:*-solved 전부]
  ─ 최종 콘솔 soap-shelf-order(서열 퍼즐, gate 없음) → door:hygiene-open → 출구
```

- 4개 puzzle 오브젝트는 방 안에 흩어 배치, 순서 무관하게 아무 것이나 먼저 풀 수 있다.
- 정리대 코너는 4개 퍼즐을 전부 풀어야 봉인이 걷힌다 — 방탈출 밀도를 담당.
- 최종 콘솔은 **키패드가 아니라 서열 퍼즐**이다: 물건 4개(설거지 세제·로션·치약·샴푸)를
  적은 양부터 순서대로 눌러 올리면 그 자체로 `door:hygiene-open`을 발화한다(탈출키트의
  잠금 3단계 중 ③, 한국사 드라이런과 동일 패턴 — 전 순열 유일해 검산 대상).

## 정보 배정표 (코드 조각 대신 — 각 퍼즐이 공개하는 정보)

이 방은 숫자 키패드가 아니므로 "코드 조각"은 없다. 대신 각 퍼즐이 발화하는 이벤트가
정리대 코너의 봉인 조건이다.

| 퍼즐 | 근거 문항 | 조작 | 판정 핵심 | 보상(이벤트) |
|---|---|---|---|---|
| P1 toothpaste-squeeze | HY-001 | **탭으로 짜기**(누를 때마다 덩어리 증가, "그만" 확정) | 완두콩 크기 구간 | `code:tooth-solved` |
| P2 hand-sanitizer-pump | HY-004 | **탭으로 펌프 횟수 세기** | 1~2회 | `code:sani-solved` |
| P3 brushing-timer | HY-009 | **관찰 후 "지금!" 탭**(4부위 순환 애니메이션) | 4부위 각 1회 이상 노출 후 | `code:brush-solved` |
| P4 toilet-paper-pull | HY-005 | **탭으로 당기기**(누를 때마다 길이 증가, "끊기" 확정) | 손바닥 길이 구간 | `code:paper-solved` |
| 최종 soap-shelf-order | HY-019·007·001·003 | **탭으로 순서 배치**(적은 것부터) | 정답 순열 유일 | `door:hygiene-open` |

조작 4종 중복 없음: 짜서 채우기(누적 후 확정) / 횟수 세기(1탭=1펌프) / 관찰 후
단발 탭(타이밍 아님 — 애니메이션 완주가 조건) / 당겨서 늘리기(누적 후 확정).
최종 콘솔은 예외 표(curriculum-map.md)에 근거를 남기고 4문항 모두 "짜기" 계열을
재사용 — 일반화 목표(같은 조작, 다른 정답) 자체가 이 퍼즐의 개념이기 때문이다.

## P1 `toothpaste-squeeze` — 치약 짜기 (HY-001) · 하

- 칫솔 위 치약 튜브 그림. [짜기] 버튼을 탭할 때마다 치약 덩어리가 한 단계씩 커진다
  (연속 드래그 아님 — 이산 스텝 N단계). 언제든 [됐어요] 버튼으로 확정.
- 확정 시 덩어리 크기가 정답 구간(완두콩 크기 대역) 안이면 해결, 아니면 방향 피드백
  후 자유 재시도(감점 없음, 오답 카운트만 힌트 해금에 사용).
- 확정 전에는 언제든 [줄이기]로 한 단계 되돌릴 수 있다(무오류 학습 — 확인 전 관찰).
- 보상: `code:tooth-solved`.

## P2 `hand-sanitizer-pump` — 손 소독제 펌프 (HY-004) · 하

- 펌프 통 그림. 탭할 때마다 펌프가 눌리며 손바닥 위 소독제 웅덩이가 1단위씩
  늘어난다. [됐어요]로 확정. 정답은 1~2회.
- 되돌리기 없음(펌프는 실제로 되돌릴 수 없는 동작이라는 자연스러운 제약을 그대로
  둔다) — 대신 확정 전 웅덩이 크기가 항상 보인다.
- 보상: `code:sani-solved`.

## P3 `brushing-timer` — 양치 시간 (HY-009) · 중

- 입 안 그림에서 앞니·왼쪽 어금니·오른쪽 어금니·안쪽이 순서대로(약 1.2초 간격)
  한 번씩 밝아지는 애니메이션이 반복 재생된다. [지금!] 버튼은 **네 부위가 모두 한
  번씩 밝아진 뒤부터** 눌러야 정답으로 인정된다 — 그 전에 누르면 "아직 안 닦인
  부위가 있다"는 방향 피드백.
- 반응속도를 재는 것이 아니라 "네 부위를 다 봤는가"라는 관찰 판단만 남긴다
  (curriculum-map.md 예외 표 참조 — HY-009 원본과의 의도적 차이).
- 보상: `code:brush-solved`.

## P4 `toilet-paper-pull` — 화장실 휴지 (HY-005) · 하

- 휴지 롤 그림. [당기기] 탭마다 풀려나온 길이가 늘어난다. [끊기]로 확정.
  정답은 손바닥 위 서너 번 접히는 길이 구간.
- 확정 전 [말아넣기]로 한 단계 되돌리기 가능.
- 보상: `code:paper-solved`.

## 최종 `soap-shelf-order` — 정리대 서열 퍼즐 (HY-019·007·001·003) · 중상

- 4개 퍼즐을 모두 풀면 정리대 봉인이 걷히고 이 장치가 열린다.
- 화면에 물건 4개(설거지 세제·로션·치약·샴푸) 카드가 뒤섞여 표시된다. **적게 쓰는
  것부터 많이 쓰는 것 순서로** 하나씩 탭해 선반 4칸에 놓는다(되돌리기 1단계 지원).
- 정답 순서(각 문항의 "알맞은 양" 구간 중앙값 오름차순, `autoplay.ts`가 유일 정답
  임을 순열 전수로 검산): 설거지 세제 HY-019(23.5) → 로션 HY-007(31) →
  치약 HY-001(36.5) → 샴푸 HY-003(41.5).
- 다 놓으면 즉시 채점(정답이면 `door:hygiene-open` 발화, 오답이면 방향 피드백 후
  선반을 비우고 재시도).
- 힌트 단계: ① "머리 감을 때랑 컵 하나 씻을 때, 어느 쪽에 손이 더 많이 갈까?"
  ② "제일 적게 쓰는 건 컵 하나 씻는 세제야." ③ 정답 순서 중 인접 두 개를 직접 알려줌.
