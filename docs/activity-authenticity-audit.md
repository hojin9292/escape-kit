# 6개 방 활동 현실성 점검

점검 기준은 세 가지다. 실제 생활에서 관찰 가능한 단서가 있는지, 상황에 따라 달라지는
양을 보편 규칙처럼 가르치지 않는지, 반응속도나 반복 탭이 학습 목표를 가리지 않는지 확인했다.

| 방 | 유지한 활동 | 맥락을 보강한 활동 | 구조를 교체한 활동 |
|---|---|---|---|
| 깨끗한 방 | 치약 짜기 | 소독제는 제품 안내량, 양치는 빠진 부위 확인, 휴지는 이번 연습의 세 칸 | 없음 |
| 먹고 마시는 방 | 없음 | 물은 컵 안전선, 얼음은 주문표의 2~3개 | 잼 격자 탭 → 직접 문질러 고르게 바르기, 요거트 자동 타이밍 → 주문표와 세 그릇 비교 |
| 말하고 듣는 방 | 없음 | 조용한 도서관·바로 옆 친구, 도움이 필요할 때 선생님 부르기, 상대가 고개 드는 신호, 2~3문장 뒤 표정 확인 | 없음 |
| 함께 지내는 방 | 엘리베이터 거리 | 친구 책과 시야를 가리지 않는 옆쪽 접근 | 어깨 두드리는 힘 → 말로 부탁하고 기다리기, 가방 크기 조절 → 버스에서 놓을 곳 고르기 |
| 물건 쓰는 방 | 연필 잡기, 수도꼭지, 책 쌓기 | 결과 단서(글씨·물 튐·흔들림)를 판정 기준으로 유지 | 풀칠 격자 탭 → 종이에 직접 문질러 네 귀퉁이·가운데 확인 |
| 시간과 기다림 방 | 횡단보도 | 전자레인지 완료음·제품의 뜸 들이기 안내, 친구가 문장을 끝내고 바라보는 신호 | 숙제 확인 횟수 → 이름·빠진 칸 체크리스트 |

각 방의 마지막 활동은 새 규칙을 추가하는 퀴즈가 아니라, 앞에서 수행한 네 활동을 다시
확인하는 복습 보드로 유지했다. 따라서 전체 구성은 핵심 활동 24개와 복습 보드 6개다.

## 2026-09 생활 기준 재점검

핵심 활동 24개와 복습 보드 6개를 다시 확인했다. 주문표·제품 라벨·컵 안전선처럼
상황 안에 기준이 있는 활동은 유지하고, 화면의 표현과 판정이 실제 행동을 오해하게 하는
다음 여섯 항목을 수정했다.

| 활동 | 발견한 문제 | 수정한 기준 |
|---|---|---|
| 치약 짜기 | 정답 그림이 쌀알처럼 작고, 거품 양을 세정 근거로 설명함 | 3세 이상 완두콩 크기가 칫솔모 폭과 비교해 보이도록 확대하고 불소치약·뱉기 중심으로 설명 |
| 수도꼭지 | 물을 많이 틀수록 물줄기가 길어져 양을 잘못 표현함 | 물줄기 거리는 고정하고 5초 동안 계량통에 받은 약 0.3~0.5L로 비교 |
| 손 소독제 | 화면 라벨은 1회인데 판정은 2회도 정답이었음 | 제품 라벨과 같은 1회만 정답, 실제 제품에서는 라벨 확인과 손 전체 도포를 우선 |
| 양치 시간 | 몇 초짜리 애니메이션이 실제 칫솔질 시간처럼 보일 수 있음 | 실제 약 2분을 네 구역·각 약 30초로 줄여 보여주는 연습임을 명시 |
| 화장실 휴지 | 세 칸을 모든 상황의 충분량처럼 읽을 수 있음 | 먼저 세 칸을 접고 실제로 부족하면 필요한 만큼 추가하는 맥락으로 제한 |
| 전자레인지 | 완료 뒤 늦게 누르면 실패·음식이 식는다고 가르침 | 포장지의 뜸 들이기 시간을 확인하고, 완료 뒤 조금 늦는 것은 실패 처리하지 않음 |

외부 기준은 [미국치과협회 치약·칫솔질 안내](https://www.ada.org/resources/ada-library/oral-health-topics/toothbrushes),
[EPA WaterSense 세면대 수도 유량 기준](https://www.epa.gov/watersense/bathroom-faucets),
[CDC 손 소독제 사용 안내](https://www.cdc.gov/clean-hands/about/hand-sanitizer.html),
[USDA 전자레인지 뜸 들이기 안내](https://www.fsis.usda.gov/food-safety/safe-food-handling-and-preparation/food-safety-basics/cooking-microwave-ovens)를 대조했다.
