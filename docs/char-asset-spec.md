# 호진티 주인공 스프라이트 가공 규약

현재 주인공은 사용자가 제공한 **호진티 한 명**이다. 원본 턴어라운드는
`assets-src/gen-src/hojinti-turnaround.png`이며, 자홍 배경의 한 행에 정면·¾정면·
측면·¾후면·후면 순서로 다섯 뷰가 있다.

## 방향 매핑

| 화면 방향 | 원본 뷰 |
|---|---|
| 아래 `s` | 정면 |
| 아래-오른쪽 `se` | ¾정면 |
| 오른쪽 `e` | 측면 |
| 위-오른쪽 `ne` | ¾후면 |
| 위 `n` | 후면 |
| 위-왼쪽 `nw` | ¾후면 좌우 반전 |
| 왼쪽 `w` | 측면 좌우 반전 |
| 아래-왼쪽 `sw` | ¾정면 좌우 반전 |

## 재가공

```bash
node scripts/import-char.mjs
```

이 명령은 자홍 키잉과 외곽 페더링을 적용하고, 280×260 투명 캔버스에 각 뷰를 맞춘 뒤
`assets-src/ext-char/char-m-{방향}-{idle,a,b}.png` 24장을 만든다. 걷기 프레임은
호진티의 짧은 다리를 잘라 움직이지 않고 몸 전체를 ±1.4° 기울여 부드럽게 보이게 한다.
`meta.json`의 화면 배율은 1이다.

## 확인 항목

1. 아래 이동에서 얼굴, 위 이동에서 등, 좌우 이동에서 옆모습이 보이는지 확인한다.
2. 안경·이마 소용돌이·주황색 더듬이와 가방이 모든 방향에서 유지되는지 확인한다.
3. 타이틀 다음 소개 화면에 `char-m-se-idle.png`가 선명하게 보이는지 확인한다.
4. `npm run assets && bash scripts/verify.sh quick`을 실행한다.
